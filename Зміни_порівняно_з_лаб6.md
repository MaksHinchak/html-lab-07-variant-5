# Що змінилося порівняно з лабораторною №6

У №6 основним новим матеріалом були SVG-малюнок, текст по кривій та SVG-анімації. У №7 до цього самого сайту додано роботу з подіями, об’єктом документа, текстом і масивами через JavaScript.

## Нові файли

| Файл | Що робить |
| --- | --- |
| `javascript.html` | Сторінка з трьома задачами варіанта 5, двома інтерактивними зображеннями та журналом. |
| `assets/js/tasks.js` | Запускає Run Task, пошук слів та Array Task. |
| `assets/js/events.js` | Реагує на дії з текстом і зображеннями; додає повідомлення до журналу. |
| `assets/css/javascript.css` | Оформлює форми, журнал і стани елементів після наведення чи натискання. |
| `report/lab7-javascript-variant5.pdf` | Новий звіт із прикладами, перевірками й посиланням на репозиторій. |
| `report/Захист.md` | Пояснення коду простими словами та порядок показу викладачу. |
| `report/check-results.json` | Фактичні результати перевірок у Chrome. |

## Які задачі виконано

1. Спільне завдання №1: на `index.html` у BODY додано обробники `load`, `pageshow`, `pagehide`, `focus`, `blur`, `resize`, `beforeprint`, `afterprint`, `online`, `offline`, `hashchange`. Виводяться повідомлення.
2. Спільне завдання №2: заголовки, `b` і `i` реагують на наведення, натискання, відпускання, одинарне та подвійне клацання. Змінюються фон, виділення, колір і нахил. Події також записуються до журналу.
3. Варіант 5, пункт 3.5: Run Task збирає доступні властивості `document` та виводить їх у `textarea`.
4. Додатковий пункт №4: кілька зображень реагують на мишу. При наведенні змінюється насиченість, при натисканні - масштаб та рамка.
5. Варіант 5, пункт 5.2.5: пошук регулярними виразами слів, які починаються на «п» та закінчуються на «я».
6. Варіант 5, додатковий пункт 6.5: із масиву A створюється масив B без нульових елементів.

## Змінені попередні сторінки

- На всіх 9 сторінках є пункт JavaScript, новий CSS, сценарій подій і журнал.
- `index.html` показує події BODY й має посилання для перевірки зміни якоря.
- `menu.html` містить посилання на нові задачі та звіт №7.
- Підписи поточної лабораторної оновлено на №7. Згадки №6 біля SVG залишаються поясненням походження малюнка.
- Шаблон `scripts/svg-page.template.html` теж отримав нові підключення й навігацію.
- Твої поточні файли №6 скопійовано як основу; сам проєкт №6 не редагувався.

## Що показати

1. `index.html`: журнал після завантаження, зміни ширини вікна та натискання «До заголовка».
2. Заголовок: наведення, одне й подвійне клацання; у журналі з’являються повідомлення.
3. Вкладку JavaScript: натиснути Run Task, прокрутити поле й знайти `URL`, `title`, `forms`, `images`.
4. Пошук інформації: початковий текст дає 6 слів.
5. Array Task: `[0, 5, -3, 0, 8, 0, -2]` перетворюється на `[5, -3, 8, -2]`.
6. Спробувати `0 -0 0.0`: результат `[]`; спробувати `2 abc`: помилка введення.
7. Навести курсор та натиснути на обидва зображення.
8. Відкрити GitHub і звіт. Детальні пояснення дивись у `report/Захист.md`.
