У методичці немає окремого списку HTML-тегів для варіанта №5. Виведення через textarea є одним із дозволених варіантів. Для текстової задачі обрано рядок 5.2.5 («п, я»), для масиву - 6.5.

Уточнення: onhaschange → onhashchange; onbeforeonload не є стандартною подією; storage повідомляє про зміну сховища іншим документом. Для виходу використано pagehide. Застарілий метатег Content-Script-Type та script language не потрібні сучасному HTML: зовнішній script без type за замовчуванням є JavaScript.

Скриншоти знято з виконаних сценаріїв у Chrome. report/check-results.json містить результати автоматизованої перевірки. Розміщення звіту в Moodle залишається окремою дією користувача.
