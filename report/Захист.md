# Лабораторна №7. Пояснення для захисту

## Як коротко розповісти про роботу

«У цій роботі я додав до сайту JavaScript. Сайт реагує на дії користувача, показує властивості документа, знаходить слова за шаблоном та створює масив без нулів. Мій варіант - п’ятий: пункти 3.5, 5.2.5 і 6.5. Додатково зроблено події миші для зображень і задачу з масивом».

## 1. Події BODY

Подія - це те, що відбулося у браузері. Обробник - код, який запускається у відповідь.

У `index.html` на BODY є, наприклад:

```html
<body onload="LabEvents.record('load', 'Сторінку повністю завантажено.')">
```

`onload` запускається після повного завантаження. `LabEvents.record` - моя функція запису повідомлення.

| Подія | Просто про значення |
| --- | --- |
| `load` | Сторінка повністю завантажилася. |
| `pageshow` | Сторінку показано, зокрема після повернення через історію. |
| `pagehide` | Поточна сторінка приховується під час переходу. |
| `focus` / `blur` | Вікно отримало / втратило фокус. |
| `resize` | Змінився розмір вікна. |
| `beforeprint` / `afterprint` | Починається / закінчилася процедура друку. |
| `online` / `offline` | Браузер повідомив про появу / втрату мережі. Це не перевірка доступності конкретного сервера. |
| `hashchange` | Змінилася частина адреси після `#`. |

Методичка просить декілька подій, а не весь наведений перелік. Запис `onhaschange` у ній є помилкою: правильно `onhashchange`. Стандартного `onbeforeonload` немає. `storage` спрацьовує через зміну сховища іншим документом, а не просто через завантаження. Для виходу використано `pagehide`, оскільки сучасні браузери не гарантують `unload`.

Події пишуться в журнал на сторінці, а не у вікна alert. Так демонстрація не блокується діалогами. Журнал містить останні 40 подій і зберігається в `sessionStorage` між переходами в межах вкладки. Якщо сховище заблоковано, журнал продовжує працювати в пам’яті.

**Показати:** завантажити головну сторінку, змінити ширину вікна, натиснути «До заголовка», відкрити друк через Cmd+P і закрити діалог. Подивитися журнал.

## 2. Текст і зображення

У `events.js` метод `querySelectorAll` знаходить заголовки `h1`–`h6`, жирний текст `b` і курсив `i`. `addEventListener` додає реакції:

- `mouseenter` / `mouseleave`: додати / прибрати підсвічення, показати повідомлення;
- `mousedown` / `mouseup`: показати стан натиснутого елемента;
- `click`: перемкнути виділення;
- `dblclick`: перемкнути інший колір та курсив.

`classList.add` додає CSS-клас, `remove` прибирає, `toggle` перемикає. Сам вигляд задано у CSS, а JavaScript вибирає, коли його застосувати.

Для двох зображень на новій сторінці та основних зображень попередніх сторінок є наведення і натискання. CSS змінює насиченість, масштаб і рамку. Повторне натискання повертає початковий стан. Enter і пробіл дозволяють зробити це з клавіатури. `aria-pressed` повідомляє, чи активний стан зображення.

**Показати:** заголовок, жирний текст, курсив та обидва зображення. Після кожної дії є повідомлення в журналі.

## 3.5. Run Task: усі доступні властивості document

`document` - об’єкт поточної HTML-сторінки. Через нього можна дізнатися адресу, заголовок, знайти форму, зображення чи інший елемент.

При натисканні Run Task:

1. `preventDefault()` скасовує звичайне надсилання форми й перезавантаження.
2. `for...in` перебирає перелічувані властивості `document`.
3. `Object.getPrototypeOf` проходить успадковані рівні об’єкта.
4. `Reflect.ownKeys` додає також неперелічувані та символьні властивості.
5. `Set` прибирає повтори назв.
6. `Reflect.get` читає значення; `try...catch` не дає недоступній властивості зупинити весь сценарій.
7. Масив рядків записується у `textarea.value`.

Виводяться всі знайдені назви, але довгі рядкові значення скорочуються, а об’єкти та функції мають короткі описи. Це перегляд властивостей, не запуск усіх методів документа.

Приклади: `URL` - адреса сторінки; `title` - її назва; `forms` - колекція форм; `images` - колекція зображень; `getElementById` - метод пошуку елемента.

У перевіреному Chrome вийшло 315 властивостей. Це не константа: в іншому браузері число може відрізнятися.

**Показати:** Run Task, прокрутити поле; через пошук браузера або копіювання знайти знайомі назви.

## 5.2.5. Регулярний вираз: слова на «п…я»

Регулярний вираз - шаблон, за яким шукається текст.

Спочатку виділяються цілі слова:

```js
const words = text.match(/\p{L}[\p{L}\p{M}]*(?:['’ʼ-]\p{L}[\p{L}\p{M}]*)*/gu) || [];
```

- `\p{L}` - літера Unicode, зокрема українська;
- `\p{M}` - комбінований знак, який може бути частиною написання літери;
- `['’ʼ-]` - допустимі внутрішні апострофи й дефіс;
- `g` - шукати всі входження;
- `u` - працювати з Unicode;
- `|| []` - якщо нічого не знайдено, використати порожній масив.

Потім для кожного слова перевіряється:

```js
/^п[\s\S]*я$/iu.test(word)
```

`^` - початок слова, `п` - перша літера, `[\s\S]*` - довільна кількість символів, `я` - остання літера, `$` - кінець слова. Прапорець `i` дозволяє великі та малі літери. `test` дає true або false.

Виділення слів перед перевіркою не дозволяє взяти тільки кінець довшого слова: «апісня» не є збігом. Українські слова не шукаються через звичайний `\w`, який не охоплює всі українські літери.

**Показати:** початковий текст дає 6 слів: Паляниця, пісня, подія, Плаття, полум’я, пір'я. Потім ввести «поле сім’я» - результат 0. Повторення однакових слів враховуються як окремі входження.

## 6.5. Array Task: прибрати нулі

Масив - упорядкований набір значень. У моїй задачі A - вхідний масив, B - новий масив без нулів.

```js
const a = tokens.map(Number);
const b = a.filter(value => value !== 0);
```

`split` розбиває введення на окремі записи за пробілами, комами або крапками з комою. `map(Number)` перетворює їх із тексту на числа. `filter` залишає тільки елементи, для яких умова `value !== 0` істинна. `!==` означає «строго не дорівнює». Порядок елементів зберігається, A не змінюється.

Перед цим перевіряється формат числа та `Number.isFinite`: літери й нескінченність відхиляються. Десятковий знак - крапка; кома тут розділяє числа. N береться з `a.length`.

**Показати:**

- A: `0, 5, -3, 0, 8, 0, -2` → B: `[5, -3, 8, -2]`.
- A: `0 -0 0.0` → B: `[]`.
- A: `-2 3.5 0` → B: `[-2, 3.5]`.
- A: `2 abc` → повідомлення про помилку.

## Що означають HTML-елементи та атрибути

Новий матеріал цієї роботи - переважно JavaScript. `form`, `input`, `textarea`, `button`, `label`, `script`, `img`, `figure` вже траплялися у попередніх роботах.

| Запис | Просте пояснення |
| --- | --- |
| `form` | Об’єднує поля однієї задачі. |
| `textarea` | Велике поле для тексту або результату. |
| `readonly` | Результат можна копіювати, але не редагувати. |
| `button type="submit"` | Запускає обробку форми. |
| `button type="reset"` | Повертає початкові значення. |
| `label for="…"` | Підпис, пов’язаний з конкретним полем через його id. |
| `script src="…" defer` | Підключає JS-файл і відкладає виконання до розбору HTML. |
| `aside` | Окремий додатковий блок; тут журнал подій. |
| `data-task`, `data-mouse-demo` | Власні позначки, за якими JS знаходить потрібні форми й зображення. |
| `role="status"` | Повідомляє допоміжним технологіям, що тут оновлюється статус. |

Для цієї методички потрібні форми, кнопки Run Task і Array Task, вхідний текст для пошуку, сценарії та виведення результатів. `textarea` є одним із дозволених способів виведення, який обрано у моїй роботі. Окремого списку обов’язкових нових тегів саме для варіанта 5 тут немає.

## Відповіді на можливі питання

**Чому немає alert після кожної події?** Методичка дозволяє різні способи виведення; повідомлення показуються на сторінці й у журналі, тому не блокують роботу.

**Чи працює без інтернету?** Задачі обробляються локально в браузері; сторонніх бібліотек і серверного надсилання немає.

**Чи можна видалити tasks.js?** Тоді три задачі не працюватимуть. Без events.js не буде реакцій тексту й зображень та функції повідомлень.

**Чим це відрізняється від №6?** У №6 основна робота - SVG-графіка й SVG-анімація. Тут додається нова сторінка з алгоритмами на JavaScript та обробка подій. Наявність JS для кнопок анімації в №6 не замінює завдання №7.
